使用條款

歡迎使用 sbgov.tw（以下稱「本服務」）。本服務提供免費二級子網域申請與對應導向機制。 當您提交申請或使用本服務所提供的子網域時，即代表您已閱讀、理解並同意遵守以下服務條款。

一、服務內容與對象

本服務開放免費申請二級子網域（格式如 *.sbgov.tw），並將其對應至使用者指定的 GitHub Pages 目標位址。 本服務保留隨時修改、暫停或終止部分或全部服務之權利，恕不另行通知。

二、禁止事項與內容規範

使用本服務提供的子網域託管網站時，嚴禁涉及以下內容或行為：

  • 惡意軟體、釣魚網站、病毒散布或詐騙行為。
  • 侵犯他人智慧財產權（如商標、著作權、專利）。
  • 散布違法內容、兒童色情、暴力、仇恨言論或賭博資訊。
  • 冒充政府機關、公家單位、知名企業或他人身分進行誤導。
  • 對本服務發起阻斷服務攻擊（DDoS）、爬蟲濫用或嘗試入侵後台。

三、子網域巡查、收回與封禁機制

本服務會不定期主動巡查所有二級子網域，確認其是否用於違法用途或有違反本服務條款之情事。 一經發現或接獲相關檢舉，管理員有權在不經事先通知的情況下，逕行立即停用、註銷或永久封禁該子網域， 且相關封禁狀態將於公開查詢系統中顯示。

若您的子網域遭到封禁且認為有誤，可透過官方聯絡信箱提出申訴與佐證。

四、免責聲明

  • 本服務為免費提供，不提供任何明示或暗示的穩定度、可用性或效能擔保。
  • 對於使用者託管於 GitHub Pages 上的內容或第三方服務中斷所造成的任何損失，本服務不負賠償責任。
  • 網域 DNS 解析或 Cloudflare 節點異動可能需要短暫生效時間，使用者需自行承擔延遲風險。

五、聯絡與濫用檢舉

若您發現任何透過本服務進行的違規、侵權或濫用行為，請附上相關證據與網址， 寄送至 abuse@sbgov.tw，我們將盡速處理。
